# noahcrousewebsite

Source for my portfolio site, live at [noahcrousewebsite.vercel.app](https://noahcrousewebsite.vercel.app).

## Pages

- **Home**: overview and current focus
- **Case studies**: project write-ups
- **About**, **Audio**, **Creative tech**, **Contact**

## Stack

Next.js (App Router), React, TypeScript, Tailwind CSS and Framer Motion. Deployed on Vercel.

## Running locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
